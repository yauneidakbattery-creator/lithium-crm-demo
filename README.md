# 锂电池CRM · 公开演示版

单文件静态演示，可放在 GitHub Pages。打开 `index.html` 即可查看客户列表、客户详情、用户权限和个人设置。

页面使用示例数据。它不连接 Google 表格，不保存输入，不提供真实登录或权限控制。正式 CRM 需要另行开发后端、身份验证和数据存储。

## 发布到 GitHub Pages

将 `index.html` 放在目标仓库默认分支的根目录。然后在仓库 **Settings → Pages → Build and deployment** 中选择 **Deploy from a branch**，选择默认分支及 **/(root)** 并保存。发布后到该页查看网站地址。
